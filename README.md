# Machine-Learning-for-Social-Data-Science-SSIM916_A_2_202526-
# Overview
This project answers the research question: To what extent can monthly U.S. Government net revenue collections be predicted using structured categorical and temporal features, and does a nonlinear ensemble model outperform a linear regression baseline? 
Dataset: U.S. Government Revenue Collections from Kaggle
Target variable (outcome): net revenue collections)  
Models: Linear Regression and Random Forest
Evaluation metrics: RMSE, MAE, R²
